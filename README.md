# Savannah Scale - Digital marketing agency

## PROJECT DESCRIPTION.
This is a 5 page responsive website built for a fictional digital marketing agency ,"Savannah Scale". The website showcases the agency's services, a brief storied background of the agency on the about page , their portfolio and provides a contact form for potential clients The primary goal was to demostrate front end web development skills using HTML and CSS, ensuring all pages are interlinked and with a consistent navigation menu added tables and lists.

## PROJECT WRITE UP.
Overview
Brand Name: Savannah Scale
Industry/ Purpose: Digital Marketing, Branding, Business Growth
Market: Kenya
Style: Professional, Persuasive, Modern
Technologies Used: HTML5 CSS3 
Overview
Savannah Scale is a website, aimed at helping businesses improve their online presence, increase brand awareness, and allow for sustainable growth within digital markets. The website has been designed specifically for companies operating within Kenya, and therefore provides a professional image for an agency offering structured marketing services. Packages are offered at scalable monthly retainer rates, denominated in Kenyan Shillings.
Purpose

Within this website, the value of the business services, available services and the different service packages are communicated to potential customers. The service packages have been divided into 3 tiers, allowing businesses to select a suitable level of services depending on their stage in digital growth.
Lead Generation

Alongside communicating information, Savannah Scale has been designed to generate leads. Through the inclusion of clear calls to actions and a pre-filled contact form, potential clients can easily make inquiries directly from the service pages. This gives a simple process from discovering to engaging with the brand.
Visual Design & User Experience
Savannah Scale employs a modern and sleek dark theme design. This gives the brand an innovative and professional look, whilst communicating technical competence. The design consists of a deep navy blue background and black areas. Rich purple areas, subtle mauve accents and pale, off white text are used throughout. This gives depth to the design, ensuring good organisation and readability.

Modern features are used throughout. Cards are used in the hero section and feature gradients. Badges take the shape of rounded pills, and call to actions are rounded. Hover effects create movement within the service and pricing cards, giving them a responsive feel.

The overall user experience is simple and easy to navigate. Clear navigation, well-organised content, responsiveness and prominent call to actions allow users to easily move around the site. This supports the brand’s image as a modern Business Growth partner.
Features & Structure
This website contains multiple pages:
Home – Contains an introduction to the brand, explaining how the business can bring digital growth. Includes a hero section to highlight key value propositions and conversion-focused CTA’s.
About – A description of the agency, and what they stand for, alongside how it can help businesses grow.
Services – Digital marketing services offered include SEO, Social Media Management, Paid Marketing, Content Marketing, Email Marketing and AI Automation.
Portfolio – More examples of creative work completed.
Contact – Allows potential customers to make enquires.
Key Features
The pricing system allows customers to easily see what retainer cost is involved in choosing the service. There are 3 packages, with the costs as follows:
Package Monthly Cost
Starter 25,000 KES
Growth 50,000 KES
Scale / Enterprise 75,500+ KES

Clear bullet points demonstrate what services will be included in each package. A comparison table can also assist customers in understanding the differences between the packages.

CTA buttons are placed strategically in order to lead from pricing to contact, passing query parameters which specify which package has been chosen. This decreases extra navigation and makes enquiring easier.
Technical Features
Basic front end technologies were used to create Savannah Scale. This has allowed for light, easy to maintain and responsive design.
HTML5 is used to add structure to the webpage. Navigation, content sections, service cards, pricing grids and contact fields have appropriate formatting.
CSS3 is used to format the design. Responsive design, Flexbox, Grid layout, gradient effects, text formatting, hover effects and variable design elements have been used. In addition, custom properties are used to easily change design across the site.
Shared CSS means that the design is consistent across each page. Custom properties mean that colour schemes, spacing and other design elements can be centralised.

The design is responsive meaning it is suitable for viewing on desktops, tablets and mobile phones.
As a whole, this website has been created to not only act as a digital leaflet, but to give structure to the branding. By clearly highlighting digital marketing services, pricing and enquiring methods, businesses value can be communicated and engagement with customers encouraged.
